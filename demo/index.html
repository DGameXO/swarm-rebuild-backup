Your page, rebuilt by a swarm of cursors.

The page wipes to a blank canvas, then a crew of multiplayer cursors draws the boxes, types the text and drops the images back in, live. When it is whole again, the overlay fades out and the real page takes over.

Pipeline

Four stages, one frame loop

No canvas recording, no video, no screenshot of the page. The engine reads the live DOM and rebuilds it with real nodes inside a shadow root.

Snapshot

The DOM is walked once. Boxes, text runs, media, lines and repeated components become a flat blueprint.

Blank

A shadow-root overlay covers the page with its own background. A hidden scroll pass wakes lazy images.

Rebuild

Agents claim tasks top-down, drag rects with a crosshair, type text with a caret and fade media in.

Hand off

The overlay fades and the real, interactive page comes back. Esc exits at any moment.

Why it feels right

Built like a library, not a demo

The engine is the original Swarm Rebuild choreography, ported to TypeScript and packaged with a small, typed surface.

Shadow DOM

Your CSS cannot leak in, the engine's CSS cannot leak out.

Real DOM

Text is rebuilt as text. It wraps, selects and scales like the original.

One frame loop

Every cursor, task and layer is driven by a single requestAnimationFrame tick.

Scroll-aware

Tasks unlock top-down as the visitor scrolls, or let autoScroll drive the camera.

Clean exit

Esc, the HUD button or stop() removes the overlay and hands the page back.

Typed end to end

Item, Task, Agent and the overlay primitives are discriminated unions. No any.
