swarm-rebuild

Your page, rebuilt by a swarm of cursors.

The page wipes to a blank canvas, then a crew of multiplayer cursors draws the boxes, types the text and drops the images back in, live.

How it works API

Four stages, one frame loop

01

Snapshot

The live DOM is walked once and turned into a flat blueprint of boxes, text runs and media.

02

Blank

A shadow-root overlay covers the page with its own background. Nothing leaks in.

03

Rebuild

Agents claim tasks top-down, drag rects, type text and fade media back in.

04

Hand off

The overlay fades out and the real, interactive page takes over. No clone left behind.

05

Respect

prefers-reduced-motion gets a calm cross-fade. Esc always exits.

06

Portable

One ESM import, no dependencies, no build step for consumers. Works on any page.

One call

createSwarm({ trigger: "load", autoScroll: true })
