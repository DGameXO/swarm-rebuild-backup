# Code of conduct

This project follows the [Contributor Covenant][cc], version 2.1.

Be direct, be kind, argue about code and not about people. Harassment,
discrimination and personal attacks are not welcome in issues, pull requests or
any other project space.

Maintainers may edit or remove contributions that break these rules, and may
block repeat offenders.

To report a problem, contact the maintainer privately through
<https://github.com/MaximeBoulle>. Reports are handled confidentially.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
